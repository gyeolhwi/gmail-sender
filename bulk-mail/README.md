# 일괄메일 발송 (Google Apps Script)

> 구글 시트에서 고객을 **체크**하고 메뉴 한 번 누르면, 내가 만든 **템플릿**으로 고객마다 이름 등을 바꿔 넣어 메일을 보냅니다.

- **데이터** Google Sheets · **발송** Gmail · **비용** 무료 (개인 Gmail 하루 100통)

---

## 🚀 설치 (3단계)

1. 구글 드라이브 → **빈 구글 시트** 새로 만들기
2. `확장 프로그램 → Apps Script`
   - `프로젝트 설정` → "appsscript.json 표시" 체크 → `gas/appsscript.json` 붙여넣기
   - `Code.gs` ← `gas/Code.gs`, 파일 추가 `Setup.gs` ← `gas/Setup.gs` → 저장
3. 시트 새로고침(F5) → 메뉴 `📧 일괄메일 → ⚙ 설치` → 권한 승인 (`고급 → 이동 → 허용`)

→ `설정`·`고객`·`템플릿`·`발송로그` 시트가 예시와 함께 생깁니다.

---

## ✏️ 시트

| 시트 | 넣을 것 |
|------|---------|
| **고객** | `선택`(체크박스)·`이메일`·`상태`·`발송일시`는 고정. **나머지 열은 자유롭게 추가** (이름, 웹사이트, 회사…) |
| **템플릿** | 한 줄 = 템플릿 하나 (`템플릿명`·`제목`·`본문`) |
| **설정** | 보내는사람_이름 · 첨부파일_링크 · 예약_일시 · 예약_템플릿 (모두 선택) |
| **발송로그** | 자동 기록 |

### 치환
- `{{열이름}}` → 고객 행의 그 열 값 (예: `{{이름}}`, `{{회사}}`)
- `{{이름|웹사이트}}` → 이름이 비어 있으면 웹사이트 값

```
제목: [안내] {{이름|웹사이트}}님께 알려드립니다
```

---

## 📨 사용

1. `고객` 시트에서 보낼 사람 ☐ 클릭 → ☑
2. `👀 미리보기` — 첫 번째 고객 기준 결과 확인 (발송 안 함)
3. `📨 발송` — 템플릿 선택 → "N명에게 발송합니다" 확인 → 발송
4. 발송 후: 체크 자동 해제, `상태`·`발송일시` 기록, `발송로그` 추가

- 템플릿이 1개면 선택 창 없이 바로 사용
- 이메일 형식이 잘못된 행은 건너뛰고 `실패`로 표시
- 이미 `발송완료`여도 다시 체크하면 다시 발송

### ⏰ 예약 발송 (1회)
1. `설정`에 `예약_일시`(예: `2026-10-05 09:00`)·`예약_템플릿` 입력
2. 보낼 사람 체크 → `⏰ 예약하기`
3. 그 시각에 **체크되어 있는** 사람에게 발송

예약 취소: `예약_일시`를 비우고 `⏰ 예약하기`.

## 🤖 clasp로 배포 (에이전트/개발자용)

```bash
npm install -g @google/clasp
clasp login                                   # 사람: 브라우저 로그인 (1회)
cd bulk-mail/gas
clasp create --type sheets --title "일괄메일"  # 새 시트 + 스크립트 생성
clasp push -f
```
사전: https://script.google.com/home/usersettings 에서 **Apps Script API 사용** (1회). 이후 설치 3단계부터 동일.

> 코드의 값은 모두 예시입니다. 실제 고객 데이터는 본인 구글 시트에만 들어갑니다.
